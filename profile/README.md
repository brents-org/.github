## What we build

| | Area | |
|:-:|---|---|
| 🎹 | **Music school** | The website, scheduling, and back office for a private piano studio. |
| 🤖 | **Agents** | AI assistants and automation that keep the household and the fleet running. |
| 🛠️ | **Personal automation** | Desktop tools, inbox triage, job search, energy and driver monitoring. |
| 🖥️ | **Fleet** | Services for a self-hosted homelab — media, dashboards, home automation, security scanning. |
| 🌐 | **Web & games** | Small standalone apps and experiments. |

Almost everything lives in one private, polyglot monorepo. Projects that are useful
beyond our walls are published as their own public repositories.

## How it's run

- **Everything as code.** Compose stacks, Ansible plays, and Terraform — including this page — are planned on the pull request and applied on merge.
- **One gate for `main`.** Every change is a PR, with static analysis, secret scanning, and dependency audits as required checks.
- **Self-hosted.** CI runs on our own runners, and the services run on our own hardware.
